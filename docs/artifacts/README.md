# Artifacts (respaldo)

Copias de respaldo de las páginas interactivas que armamos durante la ideación.
Son HTML autocontenidos; ábrelos en el navegador. Los documentos de trabajo en
markdown están en `docs/` (son la versión viva).

- `producto.html` — brief de producto de Ventana Cero.
- `alcanzabilidad.html` — el núcleo técnico (la escalera de confianza).
- `roadmap.html` — la hoja de ruta de 36h.
- `decision.html` — comparación de las ideas candidatas y por qué elegimos esta.
- `raiz-demo-descartado.html` — demo de "Raíz", una idea anterior que descartamos.
