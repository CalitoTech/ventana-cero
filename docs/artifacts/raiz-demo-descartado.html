Guion

Qué muestran en los 3 minutos

0:00 – 0:30

El problema

Un agente de programación que recuerda las "reglas del proyecto" entre sesiones. Una frase: lo que lee hoy en un issue se vuelve una regla que aplica para siempre.

0:30 – 1:20

El ataque

Un issue esconde una "convención del equipo". Días después, en otra tarea y con otra persona, el agente escribe una ruta de depuración que salta la autenticación. Tests en verde, review aprobado.

El atacante entra con un curl, en vivo.

1:20 – 2:15

La misma escena con Raíz

El PR queda retenido. Raíz quita una regla a la vez, encuentra la culpable y el grafo ilumina la cadena hasta el issue. Luego muestra 2 PRs anteriores, de otra persona, con la misma regla.

El momento sorprendente de la demo.

2:15 – 3:00

Números y cierre

Tabla de protocolos de control y una frase final: OWASP definió qué debe ser rastreable; Raíz es el cómo.

1 · Procedencia en cada escritura

Cada regla guarda de dónde vino: el equipo, un issue, un README, una dependencia o el propio agente, y si está verificada. El atacante puede reformular el texto, pero no puede cambiar de dónde vino.

2 · Atribución contrafactual

Ante una acción sensible, Raíz regenera el cambio quitando una regla a la vez, con llamadas paralelas a un modelo más chico y confiable. Si quitar una regla no verificada cambia una parte sensible (autenticación, permisos, red, secretos), el PR se retiene.

3 · Linaje y cuarentena

Cada cambio queda enlazado con las reglas que lo causaron. Cuando se descubre una regla envenenada, una consulta devuelve todo lo que tocó.

Riesgos

Lo que puede salir mal

El modelo improvisa en vivo

Modo guion con temperatura 0 y respuestas cacheadas para la demo; el video grabado queda listo como respaldo.

La atribución sale cara o lenta

Solo corre en acciones sensibles, en paralelo y con un modelo barato. Midan la latencia y muéstrenla: es un número honesto.

Prometer de más

Las cifras del benchmark en esta página son ilustrativas. En el pitch usen solo lo que midieron y citen solo fuentes que revisaron.

Alcance

Nada de GitHub real ni repos ajenos. Todo en un repo y una API de prueba propios, con datos ficticios.
